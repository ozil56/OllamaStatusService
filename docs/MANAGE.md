# OSS 网页管理（1.4.0 起提供）

将完整的 `OllamaStatusService-Windows-x64-v1.6.1.zip` 复制到每台服务器，解压到新的目录，双击 `Install.exe`，选择升级。升级前等待正在执行的任务完成，或先暂停新版 OSS 托管的下载。安装器会保留原配置、模型目录、任务记录和管理节点列表。

升级后访问 **现有 OSS 域名 + `/manage`**。本机也可访问 `http://127.0.0.1:11434/manage`。

网页与 `/manage/api/*` 共用 OSS 原有 HTTP 服务。公网入口继续使用原 Nginx Basic Auth，**没有第二套账号、密码、登录页或认证配置**；无需独立管理器，也不新增监听端口。已有反代必须像保护其他 OSS 接口一样覆盖 `/manage` 下所有路径。反代回源、域名和已有认证配置保持原样。

## 服务器和模型

- “本服务器”自动创建，通过 OSS 内部接口操作，不需要填写地址或凭据。
- 其他服务器可以添加、编辑、停用和移除。填写目标 OSS 的根地址；有认证时填写该节点**已经使用的 Nginx Basic Auth**，并非创建新账号。凭据只在服务器端保存，使用当前服务账户的 Windows DPAPI 加密，不发回浏览器。
- 选择节点后可以查看模型和大小、输入模型名下载，或者选择已安装模型删除。删除前必须输入完整模型名确认。
- 任务页支持查看进度、速度、状态，暂停正在下载的任务，继续暂停的任务，或重试失败任务。暂停通过关闭该任务的上游下载连接实现；继续向同一 Ollama 重新发起 pull，复用其保留的下载分片。

操作中的目标节点至少需要 OSS 1.3.0；暂停和继续需要 1.3.1。建议各节点统一升级到 1.6.1。无需同时升级全部节点；未升级节点仍可查看状态和模型列表。

## 从原独立管理器导入

在网页点击“导入服务器”，选择私有节点 JSON 文件。支持一次导入多台节点，已存在的相同地址会跳过。导入内容为原有节点地址和访问凭据，不改变任何 Nginx 账号。

每台 OSS 保存自己的节点列表；在其中一台导入后，就可以从该网页管理所有节点。若希望从其他 OSS 的 `/manage` 也看到同一列表，可以分别导入同一个文件。任务实际保存在目标 OSS 上，其他管理页面同步后也能看到和控制。

维护者可以在原管理器所在电脑、原 Windows 用户下导出：

```powershell
python app\export_manager.py --source 'C:\Tools\OSS-Manager\data\manager.sqlite3' --output 'C:\Migration\OSS-servers-private.json'
```

导入文件包含既有节点的访问凭据，应私人保管，不放入公开仓库或通用升级包。原数据库中的 DPAPI 密文不能直接跨 Windows 用户或服务器复制使用；通过 JSON 导入后，新 OSS 会用自己的服务账户重新加密。

## 下载与关闭行为

下载在**目标 OSS**执行。关闭浏览器、退出管理页面、关闭管理电脑，或者停止另一台只负责管理的 OSS，均不会取消目标服务器上的托管下载。

目标服务器自身关机时无法继续下载。服务恢复后，未完成的托管下载重新发起；已暂停任务保持暂停，直到点击“继续”。删除任务若因中断而结果不明，不会自动重放。实际分片复用和最终校验耗时由目标服务器的 Ollama 决定，暂停继续并不保证提高网速。

旧版通过 `/api/pull` 长连接提交的下载，不会自动被接管为托管任务。请等待其完成，再安装升级包；已使用 `/oss/model-jobs` 的任务可保留记录并继续管理。

## 数据与验证

节点列表及管理记录：`config.json` 中 `data_dir` 下的 `manage\manager.sqlite3`。目标模型任务：同目录下的 `model-jobs.sqlite3`。默认均位于 `%ProgramData%\OllamaStatusService\data`，升级保留。

访问 `/help` 应显示版本 `1.6.1`、`urls.manage=/manage`、`manage_policy.authentication=existing_reverse_proxy`。打开 `/manage` 应看到当前节点、模型列表和任务页。

`tests\manage_http.py ManageTests` 使用临时端口和模拟模型，覆盖现有 Basic Auth 代理保护、节点导入和凭据加密、模型下载删除、暂停继续、重启持久化，以及管理端退出后目标下载继续。所有测试均不访问实际模型服务器。

## TUN / Fake-IP 下载

1.6.1 在目标 OSS 服务器自动识别代理，并提供本机转发回退；网页不需要开启代理，也不需要调整网络模式。HTTPS 校验保留，已有下载不因设置变化而重启。目标 Ollama 需要支持该流程（验证基线 0.40.9）。详见 [下载网络与限制](DOWNLOAD-NETWORK.md)。
